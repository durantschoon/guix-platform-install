What these numbers are.
  • Percentiles are bucket-resolution: each is the upper bound of the bucket the percentile falls in, so it over-reports rather than interpolating a value that was never measured.
  • Histograms are cumulative since the daemon started. The “latency over time” chart differences them; everything else is lifetime.
  • The benchmark panel compares whatever scripts/benchmark-sync.sh actually ran. Without Guix installed the script records GIPS-side latency only and reports no baseline — that is a missing comparison, not a won one.
  • /metrics carries no store paths, CIDs, GNS names, keys or tokens — only fixed series names and integers.
